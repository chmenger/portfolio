💻 Portfólio Pessoal — Carlos Menger

Portfólio pessoal desenvolvido com o objetivo de apresentar minha trajetória na área de tecnologia, meus conhecimentos em programação e os projetos que venho desenvolvendo durante minha formação em Análise e Desenvolvimento de Sistemas.

O projeto também faz parte do meu processo de aprendizado em desenvolvimento web, servindo como um espaço para aplicar conceitos, experimentar soluções e aprimorar minhas habilidades.

🚧 Status do projeto: Em desenvolvimento. Algumas funcionalidades e melhorias visuais ainda estão sendo implementadas.

     Objetivo
     
Criar um portfólio digital que represente minha identidade como desenvolvedor em formação, reunindo meus projetos, conhecimentos técnicos e experiências acadêmicas em uma interface organizada, interativa e visualmente consistente.

Além de apresentar meus trabalhos, o projeto busca demonstrar minha evolução prática em desenvolvimento web, organização de código e construção de interfaces.


     Tecnologias utilizadas


HTML5: estruturação do conteúdo e das seções do site.

CSS3: estilização, identidade visual, layouts e efeitos de interação.

JavaScript: implementação de funcionalidades e interatividade.


    Proposta do projeto


O portfólio está sendo desenvolvido com foco em:

Apresentação pessoal e trajetória acadêmica.

Exibição de conhecimentos técnicos e habilidades.

Organização e apresentação de projetos desenvolvidos.

Navegação intuitiva entre as seções.

Identidade visual própria, com atenção à tipografia, cores e detalhes de interface.

Evolução progressiva da experiência do usuário e da responsividade.


     Funcionalidades e melhorias planejadas


Como o projeto ainda está em desenvolvimento, algumas etapas precisam ser concluídas ou aprimoradas:

Finalizar o layout e a identidade visual das seções.

Aprimorar a responsividade para diferentes tamanhos de tela.

Implementar e refinar as interações com JavaScript.

Revisar a navegação e o comportamento dos elementos interativos.

Organizar e apresentar os projetos com suas respectivas tecnologias e links.

Realizar testes e ajustes finais de usabilidade.

Finalizar a publicação do portfólio para acesso público.

Esta lista representa o planejamento do projeto e será atualizada conforme o desenvolvimento avançar.


    Aprendizados


O desenvolvimento deste projeto proporciona a oportunidade de praticar e aprofundar conhecimentos em:

Estruturação de páginas com HTML semântico.

Estilização e organização de layouts com CSS.

Manipulação de elementos e eventos com JavaScript.

Construção de interfaces e preocupação com a experiência do usuário.

Organização de arquivos e versionamento com Git e GitHub.

Planejamento, implementação e aprimoramento contínuo de um projeto próprio.



📌 Status atual



Este portfólio ainda não representa uma versão final. O projeto está sendo construído gradualmente, com foco no aprendizado, na melhoria do código e na criação de uma apresentação profissional dos meus trabalhos.

Novas funcionalidades, ajustes e melhorias serão adicionados ao longo do desenvolvimento.
